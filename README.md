# Rechovid

Репозиторій: https://github.com/evaholts37/rechovid · Сайт: https://evaholts37.github.io/rechovid/

Мобільний PWA для історій про важливі речі, зокрема з родинних архівів, та мистецьких робіт-відгуків на них. Оповідач публікує річ та її особисту чи сімейну історію; митець добровільно додає готову візуальну, текстову або аудіороботу. Перегляд відкритий усім, публікація в MVP — для повнолітніх.

Продукт перевіряє, чи може такий прямий відгук зблизити особистий досвід людини з сучасним мистецтвом без галерейного посередника та обов'язкового листування.

Пілот спирається на реальних учасників «Станції Сиваш». Детальні рішення щодо сценарію, згоди, меж MVP і подальшого розвитку — у [Codex.md](Codex.md).
