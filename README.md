# Rechovid

Репозиторій: https://github.com/evaholts37/rechovid · Сайт: https://evaholts37.github.io/rechovid/

Rechovid задумано як мобільну PWA для історій про важливі речі, зокрема з родинних архівів, та мистецьких робіт-відгуків на них. У цільовому сценарії оповідач сам публікує річ та її особисту чи сімейну історію, а митець добровільно додає готову роботу; публікувати можуть лише повнолітні. Тижневий пілот показує вже підготовлені матеріали без реєстрації й самостійного завантаження.

Продукт перевіряє, чи може такий прямий відгук зблизити особистий досвід людини з сучасним мистецтвом без галерейного посередника та обов'язкового листування.

Пілот спирається на фотографії з особистого архіву Валентини Тарасевич зі «Станції Сиваш» і колажі митців, створені на їхній основі. За повідомленням власниці проєкту, пані Валентина й митці згодні на публічний показ; конкретні файли та підписи ще не додано. Сценарій, межі пілота й подальший розвиток — у [Codex.md](Codex.md).
